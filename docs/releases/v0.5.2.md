# Desktop Pet 0.5.2

## English

- Start writing beside your character before setting up chat. The button in the input box takes you straight to chat settings. Your message stays there until you send it.
- If a reply fails or you stop it, click **Retry** beside the character to resend the last message. A different draft stays untouched.

## 简体中文

- 第一次聊天时，可以先写下想说的话，再从人物旁的输入框直接打开聊天设置。配好模型回来，草稿还在，由你决定什么时候发送。
- 回复失败或手动停止后，点人物旁的“重试”就能重发上一句，不用打开聊天记录，也不会覆盖正在写的新消息。

## 日本語

- チャットの初期設定前でも、キャラクターのそばでメッセージを書けます。入力欄からチャット設定を開いて戻っても、送信するまで下書きが残ります。
- 返信に失敗したり途中で停止したりしたときは、キャラクターのそばの「再試行」で直前のメッセージを再送できます。書きかけの別のメッセージはそのまま残ります。
