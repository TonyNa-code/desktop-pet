Maintenance update for Desktop Pet. Updating from 0.1.0 is recommended, especially for chat users and Linux AppImage users. Existing character packs and saved preferences remain compatible.

## Fixes

- Fixed full chat getting stuck before a message could be sent.
- Saved chat and voice API keys are cleared when the service endpoint changes. Enter the new service's key after changing its address.
- Switching interface language preserves unsaved settings and text fields.
- Background updates also preserve settings drafts; save failures keep inputs and show an error.
- Quick input and full chat share request status and conversation history. Clearing chat cancels pending replies, and replies from an earlier character or persona are discarded after a change.
- Character switches draw immediately and ignore outdated image loads. Click-only mode advances on the first click and no longer changes expressions for greetings, notifications, or long presses.
- Turning voice off stops playback and ignores pending audio. New replies replace older voice playback instead of overlapping it.
- Resizing keeps the pet within the current display's work area. Late drag updates no longer restart movement after release.
- Failed requests no longer become part of the character's conversation context or trigger voice replies.
- Voice audio downloads now share the synthesis request timeout.
- Linux systems without a secure credential store keep API keys only for the current session.
- Updated Electron and packaging dependencies, including the AppImage search-path fix in app-builder-lib.

If you previously changed to an unrelated service while leaving the API key field blank, the old key may have been sent to that service. Rotate that key with its original provider if needed.

## 简体中文

建议从 0.1.0 更新，尤其是使用聊天功能或 Linux AppImage 的用户。此版本修复完整聊天无法发送、切换语言丢失未保存输入、切换接口沿用旧密钥，以及语音下载超时等问题，并更新运行环境与打包依赖。原有角色包和已保存设置保持兼容。
