# Desktop Pet 0.5.0

## English

- Import a Live2D character from `.model3.json` or a ZIP, with the model's own expressions, motions, blinking and breathing.
- Talk beside your character. The compact input folds away after sending, replies appear above the pet, and drafts stay in sync with the full chat window.
- Choose expressions and motions for head pats, gentle taps and reply moods. Touch reactions settle back smoothly; typing or dragging interrupts them. Quiet idle and pointer tracking have separate switches.
- Use the visible menu beside the speech button for character selection, size, chat, settings and Quit. Click expression mode advances once per click, without extra changes on double clicks or long holds.
- External TTS audio can drive mouth movement, with stop and replay controls beside the character. Existing sprite characters, preferences and window recovery remain compatible.
- Include Chinese and Japanese fallback fonts so text stays readable on systems without CJK fonts, including minimal Linux installations. Fonts load locally without network requests.

**Live2D setup:** install the supported Core file locally and import your own compatible exported model. Core and sample models are not included. See the [setup and compatibility guide](https://github.com/TonyNa-code/desktop-pet/blob/v0.5.0/docs/live2d.md).

Voice, saved history, shared memories and experimental affection stay off by default. Touch reactions do not call a model service or increase affection. Chat and spoken text go only to the services you configure.

## 简体中文

- 支持从 `.model3.json` 或 ZIP 导入 Live2D 角色，使用模型自带的表情、动作、眨眼和呼吸。
- 在人物身旁直接对话。小输入框发送后收起，回复显示在人物上方，草稿与完整聊天窗同步。
- 为摸摸头、轻碰和不同回复情绪选择表情与动作。触碰结束后平滑恢复，输入或拖动会中断；低频待机动作和鼠标注视可以分别关闭。
- 对话按钮旁增加常驻菜单，可切换角色、调整大小、打开聊天或设置、退出。点击表情模式仍是一点换一个，双击和长按不会多跳。
- 外部 TTS 音量可驱动口型，人物旁可停止或重播语音。原有图片角色、设置和窗口找回功能保持兼容。
- 内置中日文备用字体，修复精简 Linux 等缺少字体的系统上文字显示为方框的问题。字体从本机加载，不联网请求。

**使用 Live2D：**在本机安装受支持的 Core 文件，再导入兼容的导出模型。安装包不附带 Core 或示例模型，操作步骤见[导入与兼容性指南](https://github.com/TonyNa-code/desktop-pet/blob/v0.5.0/docs/live2d.md#简体中文)。

朗读、保存聊天记录、共同记忆和实验性好感度仍默认关闭。触碰不调用模型服务，也不增加好感度。聊天与朗读文本只发送给你配置的服务。

## 日本語

- `.model3.json` または ZIP から Live2D キャラクターを追加できます。モデルの表情、モーション、まばたき、呼吸を使用します。
- ペットのそばで会話できます。送信後は小さな入力欄が閉じ、返答はキャラクターの上に表示されます。下書きはチャット画面と同期します。
- 頭をなでる、そっと触れる、返答の感情に表情とモーションを割り当てられます。反応後は滑らかに元へ戻り、入力やドラッグで中断します。待機動作と視線追従は別々に切り替えられます。
- 会話ボタンの横のメニューから、キャラクター、サイズ、チャット、設定、終了を選べます。クリック表情モードは一回につき一つ進み、ダブルクリックや長押しでも余分に進みません。
- 外部 TTS の音量で口を動かし、ペットのそばで停止・再生できます。既存の画像キャラクター、設定、位置の復元も引き続き利用できます。
- 中国語・日本語の代替フォントを同梱し、CJK フォントのない Linux などでも文字を表示します。フォントは端末内から読み込み、通信しません。

**Live2D の準備：**対応する Core ファイルを端末に導入し、書き出し済みモデルを追加してください。Core とサンプルモデルは同梱されません。[導入・互換性ガイド](https://github.com/TonyNa-code/desktop-pet/blob/v0.5.0/docs/live2d.md#日本語)をご覧ください。

音声、履歴保存、共通の記憶、実験的な好感度は初期状態ではオフです。触れ合いでは API を呼び出さず、好感度も増えません。会話と読み上げテキストは、設定したサービスに送信されます。
