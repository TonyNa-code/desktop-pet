# Desktop Pet 0.5.3

## English

- Chat service notices distinguish a rejected key, missing model, quota limit and temporary outage. Open settings from the bubble when a connection detail needs attention. For rate limits or outages, the notice shows a suggested wait when the provider supplies one. Retry stays manual.
- If a streamed reply cuts off, the bubble and chat history keep the part that arrived. The incomplete turn is not read aloud or included in later model requests.

## 简体中文

- 气泡会区分密钥未通过、找不到模型、额度不足和服务暂时不可用。需要改配置时可从气泡直接打开聊天设置；遇到限流或服务繁忙时，若服务商给出了等待时间，气泡也会显示。不会自动重发。
- 流式回复中途断开时，已收到的文字会保留在气泡和聊天记录中，并标明未完成。这轮内容不会朗读，也不会带入后续模型请求。

## 日本語

- 認証エラー、モデルが見つからない場合、利用枠不足、一時的な障害を区別して表示します。設定を見直す場合は、吹き出しからチャット設定を開けます。混雑やリクエスト制限で待ち時間が指定されていれば、その目安も表示します。自動再送はしません。
- ストリーミング中に返信が途切れても、届いた文章は吹き出しと履歴に残ります。未完了のやり取りは読み上げず、その後の会話の文脈にも含めません。
