# Desktop Pet 0.4.5

## English

- Fixed cancelling Quit while settings have unsaved changes. Choosing to keep editing now preserves the pet, chat windows, conversation draft and unsaved settings.
- Exit confirmation happens before any window closes. Confirming discard exits without saving those edits, and repeated Quit requests do not stack dialogs.
- Includes position memory, recovery after display changes or sleep, and the menu bar / system tray controls from 0.4.4.
- Opening the app again brings back the running pet without starting another copy. Chat opens on the pet's screen, and smaller screens retain the selected pet size while temporarily fitting the character into view.

Use this version instead of 0.4.4. Existing characters and settings remain compatible. Position stays on this device and is not sent to chat or voice services. Voice, saved history, shared memories and experimental affection remain off by default. Live2D remains outside this release.

## 简体中文

- 修复未保存设置时取消退出的问题。选择“继续编辑”后，桌宠、聊天窗口、对话草稿与未保存设置都会保留。
- 退出前先确认，再关闭窗口。确认放弃修改后正常退出，不保存被放弃的内容；重复点击退出不会叠加询问窗口。
- 包含 0.4.4 的位置记忆、显示器变化与睡眠恢复后的窗口找回，以及菜单栏 / 系统托盘入口。
- 再次打开应用会唤回原来的桌宠，不会启动两份。聊天窗在桌宠所在屏幕打开；屏幕较小时临时缩小角色，保留已选的大小设置。

请使用本版替代 0.4.4。现有角色与设置保持兼容。位置只保存在本机，不会发送给聊天或语音服务。朗读、聊天记录保存、共同记忆与实验性好感度仍默认关闭。本版不包含 Live2D。
