# Desktop Pet 0.4.4

## English

- The pet remembers where you leave it and returns there after restarting.
- Display changes and waking from sleep now trigger a position check. The pet and open chat or settings windows return to a visible work area; Quick Input stays beside the pet.
- Added a menu bar / system tray menu for Show Pet, resetting position, opening chat or settings, and quitting.
- Opening the app again brings back the running pet instead of starting a second copy. The current conversation and unsent draft stay intact.
- Chat opens on the pet's screen, and settings fit that screen when first opened. On smaller screens the pet temporarily scales down without changing the selected size.

Position is stored locally, separately from conversations, without display names or hardware identifiers. It is not sent to model or voice services. Linux tray support and window positioning depend on the desktop environment; Wayland may restrict positioning.

Existing characters and settings remain compatible. Voice, saved history, shared memories and experimental affection remain off by default. This release does not include Live2D.

## 简体中文

- 桌宠会记住你摆放的位置，重启后回到原处。
- 调整显示器或从睡眠中恢复时，重新检查窗口位置。桌宠及已打开的聊天、设置窗口会回到可见工作区，快速输入框跟随桌宠。
- 新增菜单栏 / 系统托盘菜单，可找回桌宠、重置位置、打开聊天与设置，或退出。
- 再次打开应用会唤回正在运行的桌宠，不再启动第二份，保留当前会话与未发送草稿。
- 聊天窗在桌宠所在屏幕打开，设置窗首次打开时适应当前屏幕。小屏幕下桌宠临时缩小，不改变原先选择的大小。

位置与会话分开保存在本机，不记录显示器名称或硬件标识，也不会发送给模型或语音服务。Linux 托盘与窗口定位受桌面环境影响，Wayland 可能限制程序调整窗口位置。

现有角色与设置保持兼容。朗读、聊天记录保存、共同记忆与实验性好感度仍默认关闭。本版不包含 Live2D。

## 日本語

- ペットを置いた位置を記憶し、再起動後もその場所に戻ります。
- 画面構成の変更やスリープ復帰時に位置を確認。ペットと開いているチャット・設定画面を表示領域内へ戻し、クイック入力もペットに追従します。
- メニューバー / システムトレイから、ペットの表示、位置のリセット、チャット、設定、終了を選べます。
- 起動中にもう一度アプリを開くと、二重起動せずに今のペットを表示します。会話と未送信の下書きもそのままです。
- チャットはペットと同じ画面に開き、設定画面も初回から画面内に収まります。小さな画面では選択したサイズ設定を変えずに、一時的に小さく表示します。

位置情報は会話とは別に端末内に保存され、ディスプレイ名やハードウェア識別子は記録しません。モデル・音声サービスにも送信しません。Linux のトレイ表示や位置調整はデスクトップ環境に依存し、Wayland では制限される場合があります。

既存のキャラクター・設定と互換性があります。音声、履歴保存、共有メモリ、実験的な好感度は引き続き初期設定ではオフです。Live2D は含まれません。
